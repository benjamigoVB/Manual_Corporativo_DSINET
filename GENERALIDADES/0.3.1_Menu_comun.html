0. Generalidades y Arquitectura / 0.3 Entorno de Trabajo y Barra Global / 0.3.2 Menú Común

Detalle y Acciones del Menú: Común

El menú Común agrupa las operaciones transversales de persistencia, navegación de registros, exportación y consulta fiscal activas para la ventana de trabajo en primer plano. Provee los métodos base para la administración del ciclo transaccional MDI dentro de DSI-NET Enterprise.

NOTA TÉCNICA DE CONTEXTO TRANSACCIONAL: Las acciones ejecutadas desde el menú Común afectan de manera directa a la DataWindow o ventana hija activa (MDI Active Sheet). En caso de no existir un documento o maestro abierto, los comandos de edición permanecerán inhabilitados automáticamente por el despachador de eventos de la aplicación.

2. Matriz de Atajos de Teclado y Operaciones

Listado técnico exhaustivo de comandos, combinaciones de teclas directas y el comportamiento del motor transaccional ante cada instrucción:

Opción de Menú Atajo de Teclado Tipo Requerido Acción del Sistema / Regla Operativa
Exportación Excel Ctrl + T Interoperabilidad Auto Transfiere la DataWindow activa directamente a un libro de Microsoft Excel (.xlsx) respetando los tipos de datos numéricos y encabezados.
Nuevo Ctrl + N Inicialización Sí Limpia los campos del formulario y genera un correlativo nuevo para registro, bloqueando temporalmente la concurrencia de serie.
Grabar Ctrl + G Transaccional (Commit) Sí Confirma la transacción en la base de datos (COMMIT) y valida reglas contables y fiscales predefinidas para la entidad.
Anular Ctrl + A Reversión No Revierte la transacción seleccionada, restituyendo saldos bancarios o stocks de kardex según el módulo correspondiente.
Cancelar Ctrl + L Descarte No Limpia la pantalla y descarta modificaciones no grabadas en memoria sin interactuar con los registros del motor SQL.
Insertar Ctrl + I Grilla / Detalle Sí Agrega una fila en blanco al final de la grilla de detalle activa inicializando los valores por defecto del catálogo.
Recuperar Ctrl + R Consulta SQL Auto Ejecuta la consulta SQL (SELECT) para recargar registros según los filtros de fecha o serie ingresados.
Eliminar Ctrl + E Eliminación No Suprime la fila seleccionada de la grilla (requiere confirmación explícita mediante diálogo modal).
Imprimir Ctrl + P Salida Física Auto Envía la orden de impresión directa a la impresora predeterminada o cola de spool de red según el perfil de usuario.
Impresión Previa Ctrl + M Vista Previa Auto Abre la vista previa del documento antes de la impresión física, permitiendo configurar márgenes y zoom.
Consulta RUC SUNAT Ctrl + U Integración Fiscal Sí Conecta con el servicio de consulta en línea para validar estado activo, condición de habido y domicilio fiscal en el padrón de SUNAT.
Enviar lista de precios Ctrl + O Distribución Auto Exporta y despacha el tarifario vigente a los canales de venta y vendedores móviles configurados en el sistema central.
Salir Ctrl + S Cierre MDI No Cierra la ventana transaccional en curso y libera la memoria en el cliente MDI, solicitando confirmación si hay datos sin guardar.

3. Integración con SUNAT y Exportación

Servicios integrados en el núcleo del menú Común para interoperabilidad y consulta normativa:

Componente Técnico Protocolo / Formato Regla Operativa y Arquitectura
Web Service de Validación RUC GET /api/v1/sunat/padron/{ruc_number} La invocación mediante Ctrl + U despacha un payload autenticado mediante token Bearer contra los servidores de consulta de comprobantes fiscales, autorrellenando razón social y ubigeo sin latencia.
Motor Nativo de Exportación Excel XLSX (OpenXML Compliant) El comando Ctrl + T utiliza el compilador de streams binarios de DSI-NET, eliminando la dependencia OLE de Microsoft Office local y reduciendo los tiempos de exportación en un 70%.

4. Procedimiento Paso a Paso: Ejecución de Comandos Transversales

Flujo de interacción operativa recomendado al invocar acciones desde el menú Común:

  1. Apertura del módulo o documento transaccional: Asegúrese de que la ventana operativa (ej. Facturación, Orden de Compra o Registro de Artículos) se encuentre en primer plano en el área MDI para que el despachador active los comandos del menú Común.
  2. Consulta y validación RUC SUNAT: Para registrar un nuevo cliente o proveedor, presione Ctrl + U. El sistema consultará el Web Service oficial de SUNAT para poblar de forma inmediata la razón social y la condición de habido.
  3. Persistencia de cambios (Grabar): Tras completar los datos de cabecera y grilla, presione Ctrl + G o seleccione Grabar desde el menú Común para ejecutar el COMMIT en SQL Server y validar las reglas fiscales.
  4. Exportación de resultados a Excel: Para auditar o extraer la información visualizada, presione Ctrl + T para generar de manera nativa la hoja de cálculo en formato OpenXML sin necesidad de librerías externas de Office.
