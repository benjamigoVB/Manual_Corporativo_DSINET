Autenticación de Usuario y Selección de Empresa

Guía técnica para el inicio de sesión de operadores, autenticación contra la base de datos empresarial y selección del entorno de trabajo fiscal.

IMPORTANTE: POLÍTICA DE SEGURIDAD Y CONTROL DE INTENTOS: Las credenciales de usuario son estrictamente personales e intransferibles. El motor de base de datos bloqueará el acceso tras 3 intentos fallidos consecutivos por políticas de seguridad corporativa y trazabilidad en auditoría interna.

1. Visualizador de Ventana de Login

Interfaz modal de validación de identidad e inicialización de la conexión de datos de DSI-NET.

2. Ficha Técnica de Campos de Entrada

Especificación de controles del formulario de autenticación, validaciones de interfaz y enlace con la infraestructura de base de datos.

Etiqueta Tipo Control Oblig. Formato / Ejemplo Regla de Negocio y Validación
Usuario Input alfanumérico Sí FCORDOVA Código de operador asignado en el maestro de seguridad de DSI-NET. Define qué módulos y menús se habilitan en la interfaz de trabajo.
Contraseña Input protegido (Password) Sí •••••••• Cadena cifrada de validación. Autentica las credenciales del operador contra el catálogo de seguridad antes de conceder privilegios DML.
Empresa ComboBox desplegable Sí 01. Empresa Demo Enruta dinámicamente la conexión ODBC/OLE DB al esquema contable, RUC activo y base de datos física correspondiente. Una vez seleccionada la empresa en el Login, no se puede cambiar dentro del sistema sin reiniciar la sesión.

3. Matriz de Botones y Atajos de Teclado

Operaciones directas desde el teclado y eventos del ciclo de vida de la ventana modal para máxima productividad operativa.

Control / Botón Atajo de Teclado Tipo de Acción Efecto en el Sistema
INGRESAR / Aceptar Enter / Alt + A Comando Primario Valida credenciales contra la tabla de seguridad, verifica licencias concurrentes activas y carga el panel principal.
Cancelar ESC / Alt + C Comando Secundario Cancela el intento de conexión, resetea el socket de comunicación y finaliza el proceso de ejecución de DSI-NET sin persistencia.
Cerrar Ventana [X] Alt + F4 Control de Sistema Interrumpe inmediatamente la apertura de conexión a base de datos y libera los recursos de memoria en la estación de trabajo local.

4. Políticas de Bloqueo y Control de Sesiones

Mecanismos automáticos de mitigación de intrusiones y control de concurrencia de licencias.

Escenario de Seguridad Comportamiento Operativo Impacto y Resolución
Bloqueo por Intentos Fallidos Al alcanzar el umbral de 3 intentos consecutivos incorrectos, el usuario pasa automáticamente al estado Locked. Se genera un registro automático en bitácora de auditoría SQL. El desbloqueo requiere la intervención directa del Administrador de Sistemas desde el Módulo de Seguridad y Permisos.
Sesión Concurrente Activa Si las credenciales figuran activas en otra estación de trabajo cliente, el sistema despliega un mensaje de alerta. Aplica el límite estricto por licencia de usuario nominal; solicita autorización para cerrar la sesión remota previa antes de inicializar el nuevo entorno fiscal.

5. Procedimiento Paso a Paso: Inicio de Sesión

Pasos secuenciales para ingresar correctamente a la suite corporativa DSI-NET ERP:

  1. Ejecute el cliente desktop de DSI-NET en su estación de trabajo para desplegar la ventana modal Acceso al Sistema - DSINET.
  2. Ingrese su código de operador asignado en el campo Usuario (ej. FCORDOVA) y la clave correspondiente en el campo Contraseña.
  3. Haga clic sobre el selector desplegable Empresa y escoja la razón social de trabajo (ej. 01. Empresa Demo).
  4. Presione el botón INGRESAR o pulse la tecla Enter. El sistema comprobará las licencias de usuario activas, conectará el catálogo de base de datos SQL correspondiente y cargará la barra global y entorno de trabajo.
