Requisitos del Sistema y Entorno de Ejecución

Especificaciones técnicas de hardware, compatibilidad de sistema operativo y dependencias de conectividad necesarias para la correcta ejecución del cliente ERP DSI-NET en estaciones de trabajo corporativas.

IMPORTANTE: ARQUITECTURA DE EJECUCIÓN (32-BIT): DSI-NET es un aplicativo transaccional compilado sobre arquitectura de 32 bits (x86). En entornos Windows de 64 bits, es mandatorio configurar los controladores ODBC y librerías OLE DB en el subsistema Windows\SysWOW64 para evitar discrepancias de capa de datos y bloqueos de conexión.

1. Especificaciones de Estación de Trabajo (Cliente Desktop)

El entorno operativo local procesa dinámicamente vistas transaccionales complejas mediante DataWindows nativos. Para garantizar un rendimiento óptimo en la carga de libros electrónicos y conciliaciones bancarias masivas, asegúrese de cumplir los siguientes estándares:

Componente de Hardware Requisito Mínimo Requisito Recomendado Requerido Observaciones Operativas
Procesador (CPU) Intel/AMD Dual Core 2.0 GHz Intel Core i5 / AMD Ryzen 5 o sup. Sí Mínimo para procesamiento fluido de DataWindows nativos.
Memoria RAM 4 GB 8 GB DDR4 o superior Sí Requerido para consultas masivas de saldos, kardex y reportes extensos.
Almacenamiento Libre 2 GB en disco local (C:) SSD con 5 GB libres Sí Instalación binaria y almacenamiento de temporales/caché local.
Resolución de Pantalla 1366 x 768 píxeles 1920 x 1080 (Full HD) Sí Evita el recorte de ventanas maestras y grids de comprobantes.
Sistema Operativo Compatible con Windows 7 Windows 10 hasta versión actual Sí Requiere compatibilidad con frameworks legacy y librerías de 32 bits de Windows.

2. Topología de Red y Despliegue Distribuido

Las estaciones cliente ejecutan el motor de interfaz gráfica de forma descentralizada, delegando la integridad referencial y las sentencias DML al clúster de Base de Datos SQL Server.

3. Dependencias de Software y Conectividad de Red

El runtime de ejecución requiere controladores de 32 bits específicos para intermediar la comunicación nativa entre los procedimientos almacenados y la capa de presentación.

Capa de Software Versión Requerida Configuración Obligatoria
Conector de Base de Datos Native OLE DB / ODBC SQL Server (32-bit) Configuración de DSN del sistema apuntando al servidor ERP con cifrado TLS habilitado.
Integración Ofimática Microsoft Excel 2013 o superior Requerido para importación de dietarios bancarios y exportación de reportes tabulares (xlsx/csv).
Adobe Acrobat Reader Adobe Acrobat Reader (estándar gratuito) Requerido para la visualización e importación de los PDFs y estados de cuenta bancarios.

4. Permisos y Políticas Locales de Windows

DSI-NET implementa módulos que generan cachés locales de transacciones offline y tablas temporales. Se deben configurar los siguientes parámetros de seguridad a nivel de directivas locales de endpoint:

Directiva / Parámetro Ámbito Tipo Regla de Configuración y Propósito
Privilegios y Permisos de Escritura Ruta estándar C:\DSINET Control Total El usuario operativo debe poseer permisos de Lectura/Escritura para permitir la actualización de archivos INI y generación de reportes spooler.
Exclusiones de Antivirus (EDR) Proceso binario y carpeta C:\DSINET Exclusión Endpoint Añadir exclusión en Windows Defender o EDR corporativo para evitar análisis heurísticos invasivos que bloqueen el proceso durante la generación masiva de XML de facturación electrónica.
Despliegue Corporativo (GPO) Registro de Windows (SysWOW64) Claves HKLM En despliegues bajo Active Directory (GPO), distribuir el paquete desatendido que registra las librerías runtime de PowerBuilder y crea las claves en HKLM\Software\WOW6432Node\DSISAC.

5. Procedimiento Paso a Paso: Preparación del Endpoint

Siga las etapas técnicas para preparar la estación de trabajo antes del inicio del ERP.

  1. Verificación de especificaciones de hardware: Asegure que el equipo cuente con al menos 4 GB de RAM (8 GB recomendado) y 5 GB de espacio disponible en la unidad de estado sólido (SSD).
  2. Configuración del origen de datos ODBC (32-bit): Abra el ejecutable odbcad32.exe situado en C:\Windows\SysWOW64\ y registre el DSN del sistema con los parámetros de conexión al clúster SQL Server.
  3. Asignación de privilegios sobre el directorio de trabajo: Ingrese a las propiedades de la carpeta C:\DSINET y otorgue permisos de Control Total al usuario del sistema operativo para permitir la edición de temporales e INIs.
  4. Registro de exclusiones en el motor antivirus: Incorpore la ruta C:\DSINET\ dentro de la lista de exclusiones de análisis en tiempo real para optimizar la velocidad en la emisión y firma de comprobantes electrónicos (CPE / GRE).
